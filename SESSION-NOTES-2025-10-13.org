* Process Improvements & Patterns

** 1. Draft-Review-Revise Workflow (Established)
Proven effective from CardFlight resume:
1. Create comprehensive .org draft with strategic notes
2. User reviews and adds [USER: ...] feedback markers
3. Revise based on all feedback
4. User approves strategic direction
5. Generate final HTML + resume-builder.js variant + dynamic-resume.html update

Benefits:
- Prevents wasted effort on wrong direction
- User visibility into strategic positioning before implementation
- Faster iteration on content vs formatting
- More thoughtful strategic refinement

** 2. Honest Positioning Pattern (Consistent)
Ongoing refinement based on user feedback:
- "Expert" → "Advanced" or "Intermediate" with qualifiers
- "Built" → "Contributed to" (more accurate)
- Verify company locations (don't assume local)
- Remove unfounded metrics
- Accurate contributions vs ownership claims

Result: More credible, trustworthy resumes

** 3. Branch Organization Discipline
Lesson learned:
- Keep work focused to branch purpose
- Don't mix unrelated work (slash commands vs resume generation)
- Regularly check branch status and PR progress
- Clean up merged branches promptly

* Technical Learnings

** 1. PR Review Process
- Claude Code can review PRs and provide detailed feedback
- Reviews identify: syntax issues, security gaps, best practices
- Commit 6a7bd6b showed proper response to review:
  - Fixed all critical issues
  - Enhanced with additional checks
  - Tested changes
  - Clear commit message documenting fixes

** 2. Git Branch Management
- Divergent branches require reconciliation strategy
- Options: merge, rebase, fast-forward only
- Configure preference: `git config pull.rebase false` (merge)
- Check PR status regularly: `gh pr list`, `gh pr view <number>`

** 3. GitHub CLI Usage
- `gh pr list` - List open PRs
- `gh pr view <number>` - View PR details
- `gh pr view <number> --comments` - View PR with review comments
- `gh pr merge <number> --squash` - Merge PR with squash strategy
- Clean interface for PR management without leaving terminal
